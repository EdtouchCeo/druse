# 학생부 분석 종합 단계 오류 수정

2026-09-29 · 로컬 앱 1.1.2

구간별 학생부 분석을 모두 마쳤더라도, 종합 단계의 AI 응답에서 근거 번호가 중복되거나 잘못된 항목에 속하거나 허용 개수를 넘으면 전체 결과를 저장하지 못하는 문제가 있었다. 화면에는 ‘통합 분석이 선택한 검증 후보나 항목 수를 확인할 수 없습니다’라는 메시지가 표시됐다. 이 메시지만으로 실제 응답이 어떤 조건을 어겼는지는 구분할 수 없다.

## 수정한 처리

1. 같은 근거 번호를 반복한 응답은 한 번만 반영한다. 번호 양끝의 공백은 정리하되, 없는 번호나 다른 항목의 번호를 추측해서 바꾸지 않는다.
2. 종합 요청마다 실제 선택 가능 개수를 명시한다. 중간 묶음의 제한과 최종 제한을 구분하며, 재요청에는 문제가 생긴 항목과 위반 조건을 전달한다.
3. 종합 응답을 다시 요청해도 검증에 실패하면, 이미 원문 인용과 내용 검사를 통과한 모든 구간의 분석을 모아 결과를 만든다. 실패한 종합 응답의 요약·질문·판단은 사용하지 않는다. 관찰·인용·제안·산출물·교사 도움을 보존하고 동일한 내용만 정리한다.
4. 이 경우 화면과 PDF에 **구간별로 검증한 분석을 모은 결과이며 제안의 중복과 우선순위는 교사가 확인해야 한다**고 표시한다. AI가 종합 선택을 성공한 결과로 표시하지 않는다.

학생부 구간 자체의 원문 인용 검증이 실패하면 기존처럼 저장을 보류한다. 작업 취소, 모델 연결·메모리 오류, 교사 계정 변경, 교사의 동시 편집 충돌도 완료 처리로 바꾸지 않는다. 생성 결과는 모든 원문 구간의 검사가 끝난 뒤 기존 저장 절차를 거쳐 반영한다.

## 기존 작업을 다시 진행하는 방법

기존 실행기에서 작업을 완료하거나 취소한 뒤 `Ctrl+C`로 종료하고, 1.1.2 폴더의 `상담실_교사용.cmd`를 실행한다. 학생을 선택한 뒤 상단 **분석 작업 상태**를 확인한다.

- **1.1.1에서 중간 저장한 학생부 분석:** 자료·회차·분석 방향·설치 모델이 같으면 **저장 구간부터 이어서 분석**을 사용한다. 해당 출시 버전의 저장 방식만 호환하며, 개별 요청과 인용을 현재 기준으로 다시 검증한다. 종합 요청은 수정된 기준으로 진행한다.
- **1.1.0 또는 중간 결과가 없는 작업:** 학생부 상세 분석을 다시 실행한다. 이전 버전에 저장되지 않은 중간 결과는 복원할 수 없다.
- **자료나 모델이 바뀐 작업:** 현재 자료로 분석을 새로 시작한다. 이전 학생부의 중간 결과를 섞지 않는다.

## 검증

실제 학생 자료를 사용하지 않고 합성 자료로 다음을 확인했다.

| 검사 | 결과 |
| --- | --- |
| 종합 선택·원문 검증·분량·이어하기 | 79개 통과 |
| 분석 PDF·교사 보고서·삭제·접근 권한 | 38개 통과 |
| 타입 검사와 배포용 화면 빌드 | 통과 |
| 종합 오류 재현 화면 | 잘못된 근거 번호를 두 번 반환해도 원문에 연결된 두 구간의 분석을 저장하고, 안내 문구와 분석 PDF를 표시함 |
| 새로고침·취소·이어하기 화면 | 진행 중인 학생 선택 복구와 검증한 구간부터 이어하기 통과 |
| 실행본 묶음 구성 | 7개 검사 통과 |
