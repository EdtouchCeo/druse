# 로컬 AI 항목 추출 보조

학생부 PDF 화면의 `추출 후 로컬 AI로 항목 경계 확인`은 기본으로 선택되어 있다.
설치한 로컬 모델이 연결되면 기본 추출을 저장한 뒤 로컬 검토 작업을 실행한다.
모델이 없으면 기본 추출을 표시하고, 연결 후 `로컬 AI로 항목 다시 확인`으로 재실행할 수 있다.
스캔 페이지는 기존 로컬 이미지 판독 경로를 사용하며 이미지 모델이 필요하다.

## 검토 범위

- 동일 학년도·학년·학기·학교급이고 같은 페이지에 걸친 인접 항목 중 창체 하위 항목,
  항목명과 본문이 같은 줄인 항목, 판독 불확실 항목의 경계를 검토한다.
- 원문 줄, 페이지와 줄 번호, 원문에 있는 항목명을 제공한다. 모델은 경계 위치만 반환한다.
- 원문 줄 순서를 유지하고 모든 줄이 정확히 한 번 남는지 검사한다. 모델이 반환한 문장은 저장하지 않는다.
- 항목명 옆에 인쇄된 본문은 해당 항목에 유지한다. 다른 페이지·학년도 등으로 이동하지 않는다.
- 교사가 메타데이터를 확인한 항목과 OCR 항목은 자동 경계 변경에서 제외한다.
- 최대 64줄·입력 18,000바이트의 인접 항목을 검토하며, 초과하면 자르지 않고 제외한다.
  한 번에 최대 8줄까지 경계를 이동한다. 빈 항목 생성·항목 통합·새 항목명 추정은 하지 않는다.
- 판단 보류, 잘못된 응답, 연결 실패 시 해당 구간은 유지한다. 연결 실패는 후속 추론을 중단한다.
- OCR 글자의 정확성은 이 줄 보존 검사로 보장되지 않는다. 원본과 대조해야 한다.

## 기록 보존

기본 추출은 AI 실행 전에 저장된다. 취소와 충돌 시 AI의 부분 결과는 저장하지 않는다.
원문 파일 해시는 유지하고, 변경 항목의 ID와 근거 위치·본문 해시를 재생성한다.
추출 내용이 달라지면 분석·문체 검토를 해제한다. 교사 작성 전략과 전략 이력은 보존하며,
기존 준비 보고서는 기존 source_hash 비교를 통해 이전 근거로 작성한 결과임을 표시한다.
원문 위치 정보만 추가되거나 경계가 유지되면 기존 분석을 보존한다.
이전 버전의 추출 결과는 보관된 PDF와 항목 ID·본문이 일치할 때만 위치 정보를 보완한다.
백업에서 가져온 미검증 원문은 PDF를 다시 불러온 뒤 사용할 수 있다.

## 하네스

`python -X utf8 scripts/verify-counseling.py --extraction`

합성 PDF의 정답 경계 이동, 문장·숫자와 순서 보존, 악성·불완전 모델 출력 거부,
학년도·페이지·교사 확인 범위 보존, 취소·수정 충돌, UI 자동 실행·재시도·모델 없음·실패 시 보존을 검사한다.
모델 응답을 고정한 테스트는 처리 경로 검증이며 실제 모델의 분류 정확도 측정이 아니다.
실제 학생부에 대한 정확도 향상 수치는 별도의 교사 검수 정답 자료로 측정해야 한다.

설치된 `gemma4:latest`로 합성 경계 사례 1건을 실행했다. 모델은 판단 보류를 반환했고,
원문 줄·순서 보존은 통과했으나 정답 경계로 자동 수정하지는 못했다.
이 검사는 실제 로컬 추론과 보존 동작의 확인이며 정확도 향상 근거로 사용하지 않는다.
