# 전략 생성과 분석 PDF 수정

2026-09-18, 로컬 앱 1.0.1.

- 상담 화면의 전략 생성은 목표가 하나이면 실제 대학·학과 전략 작업을 요청한다. 여러 목표이면 대학·학과 선택 화면을 연다.
- 완료된 분석을 사용하는 전략 생성에 로컬 Ollama의 현재 연결 여부를 요구하지 않는다.
- 생성 진행 상황과 오류를 대시보드 버튼 바로 아래 표시한다. 지원하지 않는 연결이나 잠긴 회차를 조용히 종료하지 않는다.
- 분석 PDF는 역량별 분석 항목·준비 제안 수를 먼저 보여 주고, 판단과 다음 준비를 열로 구분한다. 반복되는 ‘관찰과 현재의 의미’ 소제목을 제거하고 공통 평가 기준을 뒤로 옮겼다. 저장된 판단과 조건은 보존한다.

검증: 프런트엔드 타입 검사·빌드, 브라우저 모의 API 흐름 4개, PDF 관련 Python 테스트 22개 통과. 실제 외부 AI 서버 호출은 검증하지 않았다. 전체 프런트엔드 단위 테스트는 실행 환경의 `uv_os_get_passwd ENOMEM` 오류로 시작하지 못했다.

반영하려면 기존 로컬 서버를 종료한 뒤 수정본 실행기로 다시 시작한다. 기존 PDF는 자동 변경되지 않으므로 결과 화면에서 다시 저장한다.
