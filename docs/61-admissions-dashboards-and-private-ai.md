# 학종 준비 대시보드와 로컬·외부 AI 처리 경계

상태: **0.9.0 구현 기준 문서 · 2026-09-17 · 배포용 구현·검증 기록**. 3단계 대시보드, 로컬 분석, 분류 기반 외부 전략 생성 경로와 단계별 PDF가 코드에 반영되었다. 가상 분류 프로필을 사용한 실제 외부 모델 검증은 아래에 별도로 기록하며, 운영 계정의 전체 사용 흐름과 구분한다. 사용자 절차는 [교사용 이용안내](학종_전략실_교사용_이용안내.md)를 따른다.

## 구현된 작업 흐름

**학생 자료·로컬 분석 → 결과 대시보드**에서 다음 세 결과물을 사용한다.

| 단계 | 처리와 결과 |
| --- | --- |
| 학생부 분석 | 원본 PDF의 추출·판독과 상세 분석을 교사 PC의 로컬 모델로 수행한다. 다섯 영역 대시보드와 분석 PDF로 근거·해석·한계를 확인한다. |
| 대학·학과별 학종 준비 | 현재 학생부 분석과 목표를 확인한 뒤, 허용된 학습 분류와 검토한 공개 대학 자료로 외부 AI 전략을 생성한다. |
| 질문 중심 학습 | 같은 목표의 최신 학종 준비 전략에서 질문과 개념 학습·탐구 설계를 이어간다. 검증된 앞 단계 연결 정보만 사용한다. |

전형 유형은 학생부종합으로 고정한다. 교과·논술·정시 등 다른 전형 선택을 새 준비 흐름에 추가하지 않는다. 여러 희망 목표는 **대학·학과 조합마다** 학종 준비 전략과 질문 중심 학습 전략을 각각 만든다.

교사 관찰, 상담 내용, 교사 의견은 선택 입력이다. 실제로 확인한 내용을 어느 단계에서든 더할 수 있으며, 저장 후 관련 결과를 다시 생성해야 반영된다. 시간 상한·고정 시간 배분·과제 진행 상태·점검일 관리 기능은 추가하지 않는다. 실제 과제의 제한시간·분량·제출물·자료·AI 사용 조건은 보존한다.

## 화면과 결과의 상태

대시보드는 세 단계 탭, 목표 선택 카드, 요약, 다섯 상세 영역, 항목별 연결 이유·실행 방법과 근거 펼치기를 제공한다. 로컬 근거와 공개 대학 자료를 구분하고, 내부 해시·학생 식별자·파일 경로를 설명용 메타데이터에 표시하지 않는다.

입력이나 분석이 바뀌면 기존 결과를 최신으로 표시하지 않는다. 미저장 변경에서는 최신 여부를 해제하고, 저장 후 현재 입력과 결과의 연결을 다시 확인한다. 연결을 확인하지 못했거나 다른 입력으로 만든 결과는 후속 생성·PDF 저장에서 재확인을 요구한다. 확정·안내한 회차의 수정은 새 회차에서 진행한다.

교사 계정 연결 창은 인증만 수행한다. 학생 목록·편집 화면을 열지 않으며, PC에서 연결 결과를 확인하면 닫힌다. 로그인 과정에는 원래 PC 연결을 유지하기 위한 임시 로그인 창을 사용한다. 계정 연결은 온라인 기록과 PC 기록의 병합·동기화가 아니다.

## 세 결과물의 내용 구성

### 학생부 분석

대시보드와 분석 PDF의 첫머리는 학업·진로·공동체의 **3역량과 학생부 8영역별 평가 관점**을 안내한다. 공유 자료 `analysis-criteria.json`은 프로젝트 지식베이스의 학종 시행계획과 SL-P01~SL-P10을 바탕으로 한 교육적 해석이며, 개별 대학에 공통으로 적용되는 배점표가 아니다.

1. **학습 이력과 학생부 영역 지도:** 제공 학년·학기·영역과 판독 범위, 실제 기록과 근거 위치.
2. **학업역량:** 개념 이해, 교과 학습과 탐구 방법, 질문·수정·발전 과정 및 필요한 도움.
3. **진로역량:** 관심의 출발과 변화, 관련 과목·경험, 선택 이유와 아직 확인할 부분.
4. **공동체역량:** 협업·소통·책임·배려·자기관리의 구체 행동, 개인 기여와 맥락.
5. **종합 진단:** 강점의 연결, 보완할 학습, 추가 확인 질문, 후속 준비에 사용할 판단과 한계.

학생부의 사실, 교육적 해석, 학생의 진술, 교사의 관찰·의견을 구분한다. 기록 부재를 역량 부족으로 바꾸지 않으며 임의 점수·가중치·합격률을 생성하지 않는다.

기존의 짧은 분석을 다섯 페이지 완성본으로 간주하지 않는다. 상세 기준에 미달하면 PDF에 **부분 분석 · 상세 근거 추가 필요**를 명시하고 실제로 확인한 내용만 제공한다. 원문·판독·영역별 근거와 분석 분량을 보완한 뒤 재분석할 수 있다.

### 대학·학과별 학종 준비

1. **목표와 공식 자료:** 대학·모집단위·대입 학년도, 자료의 발표 단계·확인일·적용 범위.
2. **평가와 학습 기반:** 대학의 공개 평가 관점과 학과 분야의 학습 기반을 구분.
3. **학생과 목표의 대조:** 확인한 강점·보완점이 해당 목표 준비와 연결되는 이유.
4. **준비 우선순위:** 유지할 학습, 보완할 개념·기능, 과목 선택과 추가 확인 조건.
5. **학교에서 가능한 준비:** 실제 과제·활동의 조건과 선택 가능한 대안.

학과 분야의 교육적 제안을 대학의 공식 입학평가 항목으로 단정하지 않는다. 대학별로 공개된 조건의 적용 범위를 유지하며 다른 모집단위의 예외를 옮겨 적용하지 않는다.

### 질문 중심 학습

1. **질문과 선정 이유:** 학생부 분석과 앞 단계 준비에서 출발한 중심·하위 질문.
2. **개념과 학습 방법:** 필요한 개념·기능, 자기 설명·읽기·문제 풀이·오류 수정.
3. **탐구 설계:** 자료 선정·확보 대안, 비교·실험·분석 방법, 한계와 판단 기준.
4. **학교 과제·활동 연결:** 실제 절차·산출물·평가기준·허용 조건과 역할·도움.
5. **성찰과 다음 학습:** 설명할 내용, 결과물 점검·수정 방법과 후속 질문·대안.

아직 수행하지 않은 활동·결과·성찰을 완료한 사실처럼 생성하지 않는다. 교사 수업 설계나 형성평가 계획을 학생 전략에 넣지 않는다.

## PDF 내용 기준

두 외부 전략 보고서는 목표 조합별로 각각 **다섯 본문 장, 최소 다섯 페이지**로 구성하며 긴 내용은 이어서 배치한다. 표지·목차·반복 문장·여백으로 분량을 늘리지 않는다.

저장된 결과도 다섯 영역과 영역별 세 항목 이상, 구체적인 설명·선정 이유·두 가지 이상의 방법, 영역별 충분한 본문을 갖췄는지 검사한다. 같은 상세 설명을 반복하거나 내용이 부족하면 저장을 막고 보완을 안내한다. 학생부 분석의 부분 결과와 완성된 상세 전략 PDF의 기준은 구분한다.

PDF는 로컬에서 생성하며 학생 이름 등 표시 정보는 PC에서 결합한다. 결과 생성·PDF 다운로드는 학생 공개·교사 확정과 별개이다.

## 공개 자료의 지원 범위와 한계

현재 새 전략 생성용 공개 자료는 다음 **17개 대학**에 연결되어 있다.

중앙대, DGIST, 동국대, GIST, 한국외대, 한양대, KAIST, 한국에너지공과대, 경희대, 경북대, 고려대, POSTECH, 서강대, 성균관대, 서울대, UNIST, 연세대.

학과·분야는 **29개 분류**로 연결한다. 의학, 의생명·바이오공학, 생명과학, 간호학, 약학, 컴퓨터과학·컴퓨터공학, 인공지능, 전기·전자공학, 기계공학, 화학공학, 재료·신소재공학, 건설·토목·건축공학, 환경학·환경공학, 수학, 통계학, 물리학, 화학, 경제학, 경영학, 교육학·교과교육, 심리학, 법학, 정치·외교학, 사회학, 어문학, 역사학, 언론·미디어, 디자인, 전공 탐색이다.

이는 **학문 분야의 연결 분류**이다. 각 대학에 모든 분류의 학과가 실제 개설되어 있거나 정확한 교육목표·교육과정이 검증되었다는 뜻이 아니다. 자료의 대입 학년도·캠퍼스·전형·모집단위 범위를 확인해야 하며, 다른 학년도의 시행계획은 해당 지원 연도의 확정 요건으로 쓰지 않는다.

지원되지 않는 대학·학과는 자유 입력값을 외부 요청에 넣지 않고 분류 연결을 요청한다. 확인되지 않은 조건을 추가하거나 다른 목표로 임의 변환하지 않는다.

## 실제 외부 전송 경계

새 경로는 **자유서술 요약을 보내는 방식이 아니라, PC에서 선택한 허용 코드의 학습 프로필**을 사용한다.

1. **로컬 처리:** PDF 판독·추출·상세 분석과 선택 입력의 해석을 PC에서 수행한다.
2. **허용된 요청 구성:** 대학·학과·분야 분류, 대입 학년도, 학교급·학년, 강점·보완점·관심·교과·일반화된 학교 활동 조건을 사전에 정한 값으로 새 요청에 구성한다.
3. **요청 검사:** 허용하지 않은 키·값·자유서술을 거절한다. 잘못된 입력을 학생부 원문이나 이전 전략 전체로 대체하여 재시도하지 않는다.
4. **외부 생성:** 서버가 검토한 공개 대학 자료와 허용된 학습 분류를 결합한다. 질문 단계는 서버가 검증한 앞 단계 연결 자료만 사용한다.
5. **로컬 결합:** 원래 분석 근거와 실제 과제·활동 이름·출처·조건은 PC에서 결과에 연결한다.
6. **저장·출력:** 대시보드·PDF·백업을 로컬에서 보관한다. 다음 요청에 표시용 학생 이름이나 로컬 근거가 붙은 결과 전체를 다시 보내지 않는다.

학생·교사·학교·보호자 이름, 학번·계정·연락처, 학생부 파일·이미지·추출 문장, 상세 분석 전체, 상담·교사 메모 원문, 파일명·경로·원본 해시·학생별 내부 ID는 이 요청에 포함하지 않는다. 개인정보를 제거해 달라며 원문을 외부 AI에 보내는 경로는 없다. 이 제한이 모든 상황의 완전한 익명성을 보장한다는 뜻은 아니며, 허용된 학습 특성에도 정보 전달 범위를 제한한다.

기존 온라인 일반 AI의 서버·개인 Gemini·Ollama 자유서술 전송 경로는 차단했다. 로컬의 이전 단일 전략 생성 경로도 새 3단계 작업으로 안내하며 실행하지 않는다.

## 이 프로젝트 지식베이스와 로컬 자료

지식 근거는 이 프로젝트 내부 `지식베이스`의 검토 자료이다. 인접한 다른 프로젝트의 지식베이스로 대체하지 않는다.

학교 평가과제·동아리의 실제 이름, 원문 조건과 출처 위치는 로컬에 남는다. 외부에는 허용된 일반화 활동 종류·제한 조건만 전달하고, 생성 후 해당 학교의 자료를 PC에서 대조하여 연결한다. 자료의 학년도·학년·학기와 실제 수강·참여·운영 여부를 확인해야 한다. 활동 후보를 학생의 수행 실적으로 쓰지 않는다.

새 전략 보고서는 로컬 근거 연결과 후속 단계 연결 정보를 포함하므로 **백업도 로컬 전용**이다. 학생부·분석 항목을 지우거나 개인정보 구분을 바꾸어 온라인으로 저장·가져올 수 없다. 학생 조회 응답에서도 로컬 보고서 묶음을 제외한다. 가져온 사본은 원본을 확인하고 관련 결과를 재생성한다.

## 구현 확인 범위

합성 자료를 사용한 프런트 단위 118개, 인증·대시보드 Edge 13개, 타입 검사·빌드가 통과했다. Python 전체 325개 중 3개는 기존 환경 제약으로 건너뛰었다. 검증 항목에는 원문 미전송, 허용값 검사, 이전 입력 결과 차단, 선택한 목표와 PDF 연결, 로컬 백업 경계가 포함된다. 후속 변경의 검사 기록은 [프런트 검증 이력](../apps/counseling/VERIFICATION.md)에 구분한다.

가상 분류 프로필과 운영용 `generateStrategy` 함수를 사용해 실제 Gemini 3.6 Flash를 호출했다. 학종 준비·질문 중심 학습의 각 다섯 장, 총 열 장이 내용 검증을 통과했고 실제 응답으로 만든 PDF는 각 10쪽에서 본문 보존·A4 경계와 첫 페이지 표시를 확인했다. 한 장은 서비스 오류와 내용 교정 과정에서 세 번 호출 후 통과했다. 근거는 `_workspace/private-strategy-live/`에 보존한다. 실제 학생 원문을 보낸 검증이나 운영 사이트의 계정·프록시·배포 완료 검증은 아니다.

실제 로컬 Gemma4 응답을 사용한 합성 검증에서 원문 관찰 9개에 근거한 서로 다른 판단 10개와 준비 제안 4개를 보존했다. 첫 두 묶음의 실제 응답을 변경 없이 재검증하고 마지막 묶음과 통합은 실제 로컬 모델로 다시 생성했다. 검증된 원문 인용으로 요약을 구성하고, 타인의 어려움·기록 부족을 학생의 약점으로 옮긴 판단과 원문에 없는 시기 표현을 제외했다. 다섯 장의 상세 기준을 모두 통과했으며 최종 분석 PDF는 본문 10쪽이다. 근거는 `_workspace/local-analysis-live-review/final-review-metadata.json`에 있다. 합성 자료의 결과이며 실제 학생의 교육적 판단은 교사가 원문과 대조해야 한다.
