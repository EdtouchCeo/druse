# 분석 진행 상태 확인과 이어서 분석

2026-09-29 · 로컬 앱 1.1.1

1.1.2의 [종합 단계 오류 수정](67-analysis-synthesis-recovery.md)에서는 같은 자료·모델의 1.1.1 학생부 분석 구간을 재검증해 이어갈 수 있다. 그 밖의 코드 변경이나 작업 종류에는 아래의 호환 조건을 적용한다.

학생을 선택하면 화면 상단, 학생 자료 위에 **분석 작업 상태**가 표시된다. 분석이 진행 중이면 현재 단계, 검증을 마쳐 저장한 구간 수, 최근 단계 갱신 시각과 **진행 중인 분석 취소** 버튼을 확인할 수 있다. 모델이 답변을 생성하는 동안에는 같은 단계가 오래 표시될 수 있으며 갱신 시각이 그대로라는 이유만으로 중단됐다고 판단하지 않는다.

## 화면을 새로 열었을 때

실행기가 켜져 있으면 브라우저를 새로 열거나 새로고침해도 진행 중인 작업을 다시 조회한다. 진행 중인 학생을 먼저 열고, 편집 중인 내용이 없으면 작업에 자동으로 다시 연결한다. 조회에 실패하면 **진행 상태 확인**을 누른다. 자동 연결 후 통신이 끊어진 경우 **진행 상태 다시 연결**로 결과 확인을 이어갈 수 있다.

## 취소·오류·실행기 종료 후

검증을 마친 구간이 있으면 **검증 완료 N구간 저장**과 **저장 구간부터 이어서 분석** 버튼이 표시된다. 버튼을 누르면 자료와 모델을 확인하고 완료한 구간을 재사용한다. 생성 도중이었거나 검증에 실패한 구간은 다시 처리한다. 중간 결과는 완성된 분석·보고서로 표시하지 않으며 모든 처리가 끝난 뒤 최종 결과를 저장한다.

학생부 원문, 학생 자료, 분석 방향, 면접 질문·전사본·검토 내용 또는 분석 코드가 바뀌면 이전 구간을 재사용하지 않는다. 모델 이름이 같아도 설치된 모델 파일이 바뀌면 새로 처리한다. 모델 파일 정보를 확인할 수 없는 환경에서는 중간 저장을 사용하지 않고 그 사실을 진행 상태에 표시한다.

이어하기는 학생부 분석의 근거 묶음·종합 단계와 모의면접의 질문 생성·전사본 사전 검토·종합 보고서 근거 검토에 적용한다. 스캔 페이지 판독과 항목 경계 검토도 정상 처리한 구간을 보존한다. 외부 API를 사용하는 대학별 전략 생성은 진행 상태를 다시 확인할 수 있지만 이 중간 저장 기능의 대상은 아니다. 스캔 PDF의 암호는 저장하지 않으므로 실행기를 종료한 뒤에는 암호를 다시 입력해야 할 수 있다.

## 보관과 버전 전환

중간 결과는 기존 비동기화 로컬 SQLite 저장소에 교사·학생·회차·작업별로 보관한다. 다른 교사나 학생의 결과를 재사용하지 않는다. 학생 기록을 삭제하면 중간 결과도 함께 삭제하며, 정상 완료하면 해당 작업의 중간 저장을 정리한다. 중간 결과는 다운로드 백업이나 배포 패키지에 포함하지 않는다.

1.1.0에서 진행하던 분석의 중간 결과는 소급해서 복원할 수 없다. 기존 실행기의 작업을 완료하거나 취소한 뒤 실행기 창에서 `Ctrl+C`로 종료하고, 1.1.1 폴더의 `상담실_교사용.cmd`를 실행한다. 브라우저만 닫으면 기존 실행기가 계속 작동할 수 있다. 기존에 저장한 학생부·상담·면접 자료는 같은 로컬 저장소에서 사용한다.

## 검증 범위

합성 자료로 실행기 재시작, 브라우저 새로고침, 취소 후 이어하기, 종합 단계 중단, 모델 변경, 자료 변경, 담당 교사 분리, 삭제와 교사 편집 충돌을 검사한다. 실제 학생 자료를 테스트 입력으로 사용하지 않는다.
