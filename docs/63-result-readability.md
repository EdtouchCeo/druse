# 분석·전략 결과 가독성과 검증 개선

2026-09-18

학생부 분석과 전략 결과에서 같은 설명이 반복되고, 근거·판단·실행 방법을 한눈에 구분하기 어려운 문제를 개선한다. [수성구 사용설명서의 학습 준비 화면](https://higo.today/#/strategy)을 참고하되 현재 보고서의 데이터 구조와 근거 연결을 유지한다.

## 참조에서 확인한 것

공개 사이트는 로그인 전 입력 화면까지 직접 확인했다. 인증 뒤 실제 AI 생성은 실행하지 않았다. 결과 화면은 인접 저장소 `수성구고교플랫폼`의 실제 `StrategyView.vue`와 카드 컴포넌트를 메모리에서 컴파일하고 **합성 결과를 넣은 SSR 화면**으로 데스크톱·모바일 구조를 확인했다. 참조 원본은 수정하지 않았고 외부 AI·로그인 서버를 호출하지 않았다. 외부 글꼴을 불러오지 않아 스크린샷은 시스템 글꼴을 사용한다.

참조 결과는 요약 카드 → 과제별 근거와 평가 관점 → 준비·수행·점검 → 결과물 예시 → 단계별 순서로 읽힌다. 관련 소스는 `src/views/StrategyView.vue:393`(요약), `:404`(과제 카드), `:439`(3단계), `:467`(결과물), `:479`(단계 순서)다. `netlify/functions/lib/ai-model.mjs:146`은 행동·자료·결과물·점검 기준을 연결하고 같은 문장 틀을 반복하지 않게 하며, `:157`은 항목 수와 문장 길이를 제한한다.

## 현재 플랫폼에 반영한 구조

| 읽는 목적 | 반영 내용 |
| --- | --- |
| 결과의 핵심 파악 | 저장된 강점·보완·다음 준비 또는 준비 우선순위를 상단 핵심 카드 3개로 보여준다. |
| 판단과 근거 구분 | 기존 `detail`과 `reason`을 2열로 구분하고 `steps`는 별도 색상의 실행 영역으로 배치한다. 좁은 화면에서는 읽는 순서대로 세로로 배치한다. |
| 필요한 정보에 집중 | 자료 범위와 평가 기준은 펼쳐 볼 수 있게 정리한다. 기존 근거 링크와 출처·조건은 유지한다. |
| PDF 탐색과 비교 | 첫 장의 5단계 안내로 전체 구조를 보여주고, 본문은 항목별 표로 정리해 설명·이유·실행을 비교하게 한다. |
| 생성 결과의 분량 관리 | 프롬프트의 목표 분량을 줄이고 각 항목의 역할을 분명히 한다. 기존 검증기의 필수 내용·최소 설명량·근거 조건은 그대로 유지한다. |

참조의 준비·수행·점검 3열을 그대로 이식하지 않는다. 현재 스키마의 `detail`·`reason`·`steps`를 사용하므로 기존 결과를 새로 생성하지 않아도 구조를 개선할 수 있다. 상세 정보를 단순히 잘라서 줄이지 않으며, 요약 카드가 별도의 평가나 새로운 사실을 만들어내지 않게 한다.

## 하네스에서 유지할 계약

참조 하네스의 `tests/ai-views.test.mjs:40`은 생성 당시 입력과 복사·후속 질문의 일치를, `:80`은 실패한 재생성에서 기존 성공 결과 보존을, `:93`은 취소된 늦은 응답의 덮어쓰기 차단을 검증한다. 현재 개선도 상태 보존과 실제 화면 동작을 함께 확인한다.

`scripts/verify-counseling.py --readability`는 합성 자료를 쓰는 보고서 테스트, 프런트 빌드, 대시보드 브라우저 테스트를 묶는다. 실제 모델·실제 주소 옵션과 함께 실행할 수 없다. 검증 범위는 앞 단계 결과 보존, 근거·본문 이동 링크, 320px 화면의 가로 넘침, 접힌 자료 범위와 학교 적용 조건의 보존, PDF의 구조와 본문이다. 자료를 접거나 배치를 바꾸어도 판단에 필요한 조건이 사라지지 않아야 한다.

```powershell
python scripts/verify-counseling.py --readability --list
python scripts/verify-counseling.py --readability
```

참조 검토 자료는 `_workspace/higo-readability/reference-findings.md`, `reference-result-desktop.png`, `reference-result-mobile.png`에 저장했다. 합성 검증의 통과를 실제 외부 AI 호출이나 운영 배포의 성공으로 간주하지 않는다.

가독성 하네스 `harness/counseling-runs/20260918T094642496509Z/result.json`에서 보고서 테스트, 타입 검사·운영 빌드, 브라우저 7개 흐름이 모두 통과했다. 데스크톱·390px·320px 화면과 대학·학과/질문 중심 PDF의 첫 장·상세·마지막 장을 이미지로 확인했다. 기존 결과는 다시 생성하지 않아도 새 화면·PDF 배치로 표시된다. 문장 길이와 내용 역할에 대한 생성 지침은 이후 새로 생성하는 전략에 적용된다.
