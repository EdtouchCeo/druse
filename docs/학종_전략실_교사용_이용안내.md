# 학종 전략실 교사용 이용안내

학종 전략실은 학생의 자료를 정리하고, 상담에서 함께 정한 계획을 학생에게 안내하는 공간입니다. 교사가 학생을 직접 추가하여 바로 시작할 수 있습니다.

**이용 순서:** 학생 추가 → 자료·분석 → 교사 전략 수립 → 학생 상담·반영 → 최종 결과물 → 학생에게 전달

학생의 기본자료만으로 시작할 수 있습니다. 성적표, 학생부 PDF, AI 분석을 모두 준비할 필요는 없습니다. 작성 중에는 화면 위쪽의 **저장**을 누르고 **저장된 기록** 표시를 확인해 주세요.

## 1. 전략실 열기

1. 대륜고 사용설명서에 교직원 계정으로 로그인합니다.
2. **학종 전략**에서 **학종 전략실**을 엽니다. 사용설명서의 로그인 상태가 이어집니다.
3. 로그인 안내가 나오면 **로그인하고 전략실로 이동**을 누릅니다. 로그인을 마치면 전략실로 돌아옵니다.

학교 회원 승인이 완료된 교직원은 모두 이용할 수 있습니다. 별도의 전략실 참여 승인은 필요하지 않습니다.

**화면이 열리지 않으면:** 교직원 계정으로 로그인했는지 확인한 뒤 **로그인 상태 다시 확인**을 누르세요. 학교 회원 승인 대기 중이라면 관리자에게 승인을 요청하세요.

## 2. 학생 직접 추가하기

1. 왼쪽의 **새 전략**을 누르고 **학생 직접 추가**를 선택합니다. 배정된 학생이 없으면 직접 추가 화면이 먼저 열립니다.
2. **학생 이름, 학번, 학년도, 학교급, 학년**을 입력합니다. 학번은 숫자 4~8자리로 입력하고, 학년도와 학년이 맞는지 확인합니다.
3. **학생 추가하고 전략 시작**을 누릅니다.

추가한 학생이 내 담당 학생으로 등록되고 첫 전략의 **자료·분석** 화면이 열립니다. 학생 회원가입이나 사전 배정 없이 시작할 수 있습니다.

이미 담당 학생으로 등록되어 있다면 **배정된 학생**에서 학생을 선택하고 **첫 전략 만들기**를 누릅니다. 작성하던 전략이 있다면 새로 만들지 않고 왼쪽 **학생별 전략** 목록에서 엽니다.

**이미 등록된 학번이라고 나오면:** 학년도와 학번을 확인한 뒤 배정된 학생 목록을 살펴보세요. 내 목록에 없는 학생이면 관리자에게 담당 배정을 요청하세요. 등록 후 전략 생성에 실패했다면, 선택된 학생을 확인하고 **첫 전략 만들기**를 다시 누르세요.

직접 추가해도 학생의 로그인 계정이 만들어지지는 않습니다. 이 학생에게는 최종 확정 후 **학생 안내 PDF**를 전달합니다.

## 3. 자료·분석: 아는 내용부터 입력하기

1. **자료·분석**에서 학생 기본자료를 입력합니다. 입력란이 접혀 있으면 **기본자료 입력·수정**을 누릅니다. 관심 전공이나 주제, 실제 이수 과목, 활동 경험, 학습 고민, 교사 관찰 등을 아는 만큼 적습니다.
2. 성적을 입력한다면 원자료의 과목명·학년도·학기·등급 체계를 확인합니다. 모르는 내용은 비워 둡니다.
3. **저장**을 누릅니다. 아래에 정리된 자료와 **교사가 검토할 전략 선택지**를 읽습니다.
4. 활용할 계획이 있으면 **이 계획을 교사 전략에 선택**을 누릅니다. 또는 **교사 전략 수립으로** 이동해 직접 작성합니다.

선택한 제안은 비어 있는 계획 항목과 실행과제에 반영됩니다. 내용을 읽고 학생에게 맞게 고친 뒤 저장해 주세요. 학교 과제나 활동을 참고할 때는 올해 운영 여부, 대상 학년, 실제 참여 가능 여부를 확인합니다.

**자료가 부족하면:** 관심 주제나 실제 이수 과목 하나부터 시작하세요. 확인하지 않은 성적과 경험을 추정해서 채우지 않습니다.

## 4. 교사 전략 수립: 상담에 가져갈 계획 준비하기

1. **교사 전략 수립**에서 **전략 제목**을 작성합니다.
2. **교과 계획·탐구 계획·활동 계획·학기별 계획 중 하나 이상**을 구체적으로 작성합니다. 목표 전공이 정해지지 않았다면 탐색할 방향을 적습니다.
3. **실행과제 추가**를 눌러 학생이 할 일과 점검일을 정합니다. 예: “금요일까지 수업 자료 두 개를 비교하고 공통점과 차이점을 각각 한 문장으로 적기.”
4. **전략 준비 완료·상담으로**를 누릅니다.

준비한 전략이 저장되고 **학생 상담·반영** 화면으로 이동합니다. 상담 전에 작성한 계획은 보존되며, 상담 후 바뀐 내용은 **최종 결과물**에서 수정합니다.

**AI 전략 초안**은 필요한 경우에만 이용합니다. 보낼 자료를 확인하고 **전략 초안 요청**을 누른 뒤, 답변에서 필요한 내용을 전략과 실행과제에 옮겨 적고 저장하세요. 답변이 계획에 자동으로 반영되지는 않습니다.

**준비 완료 버튼을 누를 수 없으면:** 전략 제목과 계획 항목을 확인하세요. 관심 전공만 입력해서는 준비를 완료할 수 없습니다.

## 5. 학생 상담·반영: 실제 상담 내용 기록하기

1. 준비한 전략을 학생과 함께 살펴보고, 학생의 생각과 실천 가능한 범위를 확인합니다.
2. **학생 상담·반영**에서 **상담일, 학생 반응, 합의한 방향**을 입력합니다. 세 항목은 필수입니다.
3. **수정할 점**과 **상담 요약**을 필요한 만큼 작성합니다.
4. **상담 반영 완료**를 누릅니다.

상담 기록이 저장되고 **최종 결과물** 화면으로 이동합니다. 상담 기록만으로 계획이 자동 수정되지는 않으므로, 다음 단계에서 전략과 실행과제를 직접 고쳐 주세요.

**상담을 아직 마치지 않았다면:** 실제로 확인한 내용만 작성하고 위쪽 **저장**을 누르세요. 나중에 같은 학생과 회차를 열어 이어 쓸 수 있습니다.

## 6. 최종 결과물: 검토하고 확정하기

1. **최종 결과물**에서 상담의 **합의한 방향**과 **수정할 점**을 확인합니다.
2. 전략과 실행과제를 학생과 합의한 내용에 맞게 수정합니다. **학생 안내 메시지**를 작성하고 구체적인 **실행과제를 한 개 이상** 넣습니다.
3. **자동 점검 후 직접 검토**를 누르고 표시되는 의견을 확인합니다.
4. 수정이 필요하면 내용을 고친 뒤 다시 점검합니다. 확인한 사실과 앞으로의 계획을 구분하고, 학생이 할 일을 분명하게 적습니다.
5. 확인 항목에 표시한 뒤 **교사 확인 후 확정**을 누릅니다.

확정한 회차는 보존됩니다. 이후 계획을 바꾸거나 진행 상황을 기록할 때는 **회차 추가**를 사용합니다. 확정만으로 학생에게 공개되지는 않습니다.

**확정할 수 없으면:** 상담을 완료했는지, 학생 안내 메시지와 실행과제가 있는지, 점검 후 내용을 다시 수정하지 않았는지 확인하세요. 수정했다면 다시 점검하고 확인 항목에 표시하세요.

## 7. 학생에게 전달하기

| 학생 상황 | 전달 방법 |
| --- | --- |
| 교사가 직접 추가한 학생 | **학생 안내 PDF 저장** → 인쇄 창에서 **PDF로 저장** → 저장한 파일을 학생에게 전달합니다. |
| 학생 회원 계정이 연결되고 학교 회원·전략실 참여 승인이 완료된 학생 | **학생에게 전략 안내**를 누르고 공개 내용을 확인합니다. 학생이 자신의 계정으로 전략실에서 확인할 수 있습니다. |
| 교사 PC의 별도 실행기에서 작성한 학생 | **학생 안내 PDF 저장**으로 내려받은 파일을 직접 전달합니다. |

학생에게는 최종 전략과 실행과제가 전달됩니다. 학생 기본자료, 상담 전 계획, 상담 기록, 교사 참고 메모는 학생 안내에 포함되지 않습니다.

**학생 안내 PDF**는 학생에게 전달할 문서입니다. **교사 검토용 PDF**는 상담 준비와 기록 대조를 위한 문서로 교사용 자료가 포함됩니다. 전달 전에 파일의 용도를 확인해 주세요.

**PDF 창이 열리지 않으면:** 이 사이트의 팝업을 허용하고 다시 누르세요. 학생 계정에서 안내가 보이지 않으면 **학생에게 전략 안내**를 눌렀는지, 학생 계정과 담당 교사가 연결되어 있는지 확인하세요. 관리자에게 학생의 학교 회원 승인과 전략실 참여 승인도 확인해 주세요.

## 8. 저장한 전략 이어 쓰기와 다음 상담 준비하기

1. 잠시 나가기 전 **저장**을 누르고 **저장된 기록** 표시를 확인합니다. **저장 전 변경 있음**이 보이면 아직 저장하지 않은 내용이 있습니다.
2. 다시 들어왔을 때 왼쪽 **학생별 전략**에서 이름이나 학번으로 검색하여 학생을 엽니다. 좁은 화면에서는 **학생별 전략 목록**을 먼저 누릅니다.
3. 날짜와 회차를 확인하고 작성 중인 내용을 이어 씁니다.
4. 다음 상담을 시작하거나 확정한 계획을 수정하려면 **회차 추가**를 누릅니다. 이전 자료와 계획을 확인하고 미완료 과제의 진행 상태를 점검한 뒤 새 계획을 작성합니다.

한 회차는 한 번의 전략 준비와 상담, 최종 안내를 묶은 기록입니다. 이전 회차를 눌러 지난 상담과 계획을 확인할 수 있습니다.

**전략 백업 저장**은 학생의 전략과 상담 기록을 다시 불러올 수 있도록 별도 파일로 보관하는 기능입니다. 복구할 때는 왼쪽 **전략 백업 가져오기**에서 파일을 선택하고 학생을 확인합니다. 새 사본으로 열리므로 학생과 상담 내용을 다시 확인하고 최종 전략을 검토·확정해 주세요.

**최신 기록과 달라 저장할 수 없다는 안내가 나오면:** **작성 내용 백업**을 먼저 누르고 **최신 기록 불러오기**를 선택하세요. 백업 없이 최신 기록을 불러오면 저장하지 않은 작성 내용을 잃을 수 있습니다.

## 9. 자주 막히는 상황

| 상황 | 이렇게 해 보세요 |
| --- | --- |
| 배정된 학생이 없습니다. | **새 전략 → 학생 직접 추가**로 시작합니다. |
| 학생을 추가했지만 첫 전략이 열리지 않습니다. | 선택된 학생을 확인하고 **첫 전략 만들기**를 다시 누릅니다. 창을 닫았다면 **새 전략 → 배정된 학생**에서 찾습니다. |
| 최종 결과물을 작성할 수 없습니다. | **전략 준비 완료·상담으로**를 거쳐 상담일·학생 반응·합의한 방향을 입력하고 **상담 반영 완료**를 누릅니다. |
| 확정한 내용이 수정되지 않습니다. | **회차 추가**로 다음 계획을 작성합니다. |
| AI를 사용할 수 없습니다. | 계획은 직접 작성할 수 있습니다. AI 초안은 필수 단계가 아닙니다. |
| 저장이나 연결 오류가 계속됩니다. | 작성 중인 내용을 백업한 뒤 다시 로그인합니다. 관리자에게 문제가 생긴 단계와 오류 문구를 알려 주세요. |

## 부록. 학생부 PDF를 교사 PC에서 분석하기

웹에서 기본자료를 입력해 전략을 작성하는 경우에는 설치가 필요하지 않습니다. 학생부 PDF 분석이 필요할 때만 **교사 PC용 실행기**를 사용합니다. 학생부와 분석을 활용한 전략은 해당 PC에 보관하며, 학생에게는 PDF로 전달합니다.

### 처음 한 번 준비하기

1. Windows PC에 **Python 3.11 이상**을 준비합니다. AI 분석에는 **Ollama**와 사용할 AI 모델도 필요합니다. Ollama는 이 PC에서 AI를 실행하는 프로그램입니다. 설치가 어렵다면 학교 담당자에게 도움을 요청하세요.
2. 이용안내의 **교사 PC용 실행기 내려받기**를 눌러 압축을 풀고 **상담실_설치.cmd**를 실행합니다. 처음 설치할 때 인터넷 연결이 필요합니다.
3. **상담실_시연.cmd**에서 제공된 연습 자료로 사용법을 확인할 수 있습니다. 시연 창을 종료한 뒤 **상담실_교사용.cmd**를 실행합니다.
4. **대륜고 계정으로 연결**을 누릅니다. 열린 학교 연결 창에서 로그인하고, 표시된 교사 계정과 이 PC를 확인한 뒤 **이 PC 연결**을 누릅니다. 로그인 후에도 연결 안내가 남아 있으면 **로그인 상태 다시 확인**을 누릅니다.

### PDF를 확인하고 계획에 반영하기

PC 실행기에서 **새 전략**을 눌러 학생 정보를 입력하거나, 웹에서 저장한 전략 백업 파일을 가져옵니다. 웹과 PC의 기록은 자동으로 연동되지 않습니다.

1. 학생과 전략 회차를 열고 **자료·분석 → 학생부 PDF 근거**에서 **PDF 파일 선택**을 누릅니다. PDF는 20MB·80쪽 이내여야 합니다. 암호가 있는 파일은 PDF 암호를 입력합니다.
2. **항목 추출하기**를 누르고 원래 PDF와 읽어 온 내용을 대조합니다. 읽히지 않은 부분은 원본에서 직접 확인합니다.
3. **근거를 확인하고 분석 준비**를 누르고 이 PC의 모델을 선택한 뒤 **분석 시작**을 누릅니다.
4. 분석 결과의 근거를 확인하고 필요한 경우 **강점·보완점을 전략에 반영**하거나 **실행과제 초안에 추가**를 누릅니다. 계획을 수정한 뒤 **저장**합니다.
5. 교사 전략 준비, 실제 학생 상담, 최종 검토·확정을 거쳐 **학생 안내 PDF 저장**으로 파일을 내려받습니다.

모델이 보이지 않으면 Ollama가 실행 중인지, 사용할 모델이 설치되어 있는지 확인하고 **연결 다시 확인**을 누르세요. 스캔한 PDF는 이미지를 읽을 수 있는 모델이 필요합니다. 분석에 실패하면 모델과 원본을 확인한 뒤 다시 분석합니다.

다시 이용할 때는 같은 PC에서 **상담실_교사용.cmd**를 실행합니다. 종료 전에는 전략을 저장하고 실행 창에서 **Ctrl+C**를 누릅니다. 기록은 남아 있습니다.
