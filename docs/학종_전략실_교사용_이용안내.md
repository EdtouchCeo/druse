# 학종 전략실 교사용 이용안내

학종 전략실은 **학생부의 근거를 읽고, 대학·학과별 학종 준비와 질문 중심 학습으로 이어가는 공간**입니다. 과거 기록에서 확인한 사실과 앞으로 준비할 제안을 구분하고, 학생이 무엇을 왜 어떻게 배울지 정리합니다.

2026-09-17 · **0.9.0 실행 묶음 기준 안내**. 이전 앱을 실행 중이면 저장·백업하고 실행 창을 종료한 뒤 새 묶음의 **상담실_교사용.cmd**로 다시 시작하세요. 이 안내는 구현된 사용 흐름을 설명하며, 운영 배포 완료나 실제 외부 AI 호출 성공을 뜻하지 않습니다.

**PC 작업 화면:** 학생 자료·로컬 분석 → 결과 대시보드  
**대시보드의 세 단계:** 학생부 분석 → 대학·학과 준비 → 질문 중심 학습

교사 관찰·상담·의견은 선택 입력입니다. 학생부 분석은 이 PC의 로컬 AI로 처리하고, 두 후속 전략은 허용된 분류로 변환한 학습 정보와 공개 대학 자료를 외부 AI에 전달해 생성합니다. 학생부 원본과 상세 분석·교사 메모 원문은 PC에 남습니다.

## 1. 전략실 열기

학생부 분석과 새 3단계 흐름은 교사 PC용 실행기에서 사용합니다. 처음 설치하는 방법은 부록을 참고하세요.

1. **상담실_교사용.cmd**를 실행하고 PC의 전략실 화면을 엽니다.
2. **대륜고 계정으로 연결**을 누릅니다. 인증 창에는 교사 계정 연결만 표시됩니다.
3. 로그인이 필요하면 **로그인하고 전략실로 이동**을 누릅니다. 임시 로그인 창에서 학교 계정으로 로그인하면 이 창은 닫히고, 기존 인증 창에서 계정을 자동 확인합니다.
4. 인증 창의 **이 PC 연결**을 누릅니다. PC에서 연결을 확인하면 인증 창이 닫히고 원래 작업 화면을 이어서 사용합니다.

학교 회원 승인이 완료된 교직원은 별도의 전략실 참여 승인 없이 이용합니다. 실패하면 같은 인증 창에서 다시 시도합니다. 원래 PC 화면과 연결이 끊겼다는 안내가 나오면 PC 전략실에서 연결을 다시 시작하세요.

온라인 전략실은 학교 계정 확인과 기존 온라인 기록을 사용하는 화면입니다. **계정 연결은 온라인 학생 기록을 PC로 옮기는 작업이 아닙니다.** 학생부와 새 대시보드 작업은 PC 화면에서 진행합니다.

## 2. 학생과 작업 기록 선택하기

1. 왼쪽 **새 전략**을 누르고 학생 이름·학번·학년도·학교급·학년을 확인합니다.
2. PC에서는 **첫 전략 만들기**로 시작합니다. 온라인에서 학생을 등록할 때는 **학생 직접 추가 → 학생 추가하고 전략 시작**을 사용합니다.
3. 이어 쓸 기록은 왼쪽 **학생별 전략**에서 선택합니다. 좁은 화면은 **학생별 전략 목록**을 먼저 누릅니다.

학번은 숫자 4~8자리입니다. 학생의 현재 학년과 학생부에 기록된 과거 학년·학기를 구분합니다. 직접 학생을 추가해도 학생 로그인 계정이 자동 생성되지는 않습니다.

온라인에서 같은 학번이 이미 등록되어 있거나 담당 목록에 없는 학생이면 학년도·학번·담당 배정을 확인합니다. 학생 계정의 참여 승인과 담당 연결은 관리자에게 확인하세요.

## 3. 학생 자료·로컬 분석: 현재 근거 확인하기

**학생 기본자료**에는 아는 내용을 입력합니다. **학생부 PDF 근거**에서 원문과 추출 항목을 대조하고, **학생부 상세 분석**에서 로컬 모델로 분석합니다. 성적·관찰·상담을 모두 채울 필요는 없습니다.

### 기본자료 입력 예시

| 항목 | 실제로 확인하여 적을 내용 |
| --- | --- |
| 관심 전공·주제 | 생명과학과 환경 분야의 학습 내용을 비교하며 탐색 중 |
| 학습 고민 | 표와 그래프에서 같은 조건으로 비교할 기준을 정하기 어려움 |
| 활동 경험 | 기존 실험 자료를 비교하고 해석의 한계를 토의한 경험 |
| 실제 이수 과목 | 현재 수강하거나 수강이 확정된 과목명 |
| 교사 관찰 | 학생이 설명한 비교 기준과 관찰한 행동을 구분하여 기록 |

성적은 과목·학년도·학기와 5등급·9등급·성취도 체계를 구분합니다. 서로 다른 체계를 임의로 평균내지 않습니다. 빈칸이나 학생부에 없는 기록을 학생의 부족함으로 판단하지 않습니다.

### 희망 대학·학과 입력하기

1. **기본자료 입력·수정 → 희망 대학·전공 추가**를 누릅니다.
2. 대학·모집단위·전공·대입 학년도를 입력합니다. 새 흐름의 전형 유형은 **학생부종합전형**입니다.
3. 비교할 목표가 더 있으면 행을 추가합니다. 최대 12행이며 지원 가능 횟수를 뜻하지 않습니다.
4. 학과 입력 아래의 **전략 생성에 연결할 수 있는 학과 분류**를 확인합니다. 실제 대학 모집단위 이름과 학문 분야 분류는 구분합니다.

현재 자동 생성에는 공개 자료가 연결된 **17개 대학과 29개 학과·분야 분류**를 사용합니다. 지원하지 않는 대학·학과 이름은 그대로 외부에 보내지 않고 연결 필요 안내를 표시합니다. 대학별 실제 개설 학과와 교육과정이 모두 검증되었다는 의미는 아닙니다. 모집단위·캠퍼스·해당 대입 학년도의 최종 모집요강은 공식 자료에서 확인하세요.

### 학생부 분석 확인하기

원문 PDF의 항목·학년도·학년·학기·페이지와 판독 상태를 확인합니다. 기간 정보가 잘못 읽혔다면 해당 표시를 눌러 **원문 확인 후 저장**하고 다시 분석합니다. 스캔 PDF는 이미지 판독을 지원하는 로컬 모델이 필요합니다.

**결과 대시보드 → 학생부 분석**에서는 학습 이력과 영역 지도, 학업역량, 진로역량, 공동체역량, 종합 진단의 다섯 영역을 읽습니다. **판단에 사용한 근거**를 펼쳐 사실과 해석을 대조합니다. 기존 분석의 분량이나 영역별 근거가 부족하면 PDF에 **부분 분석 · 상세 근거 추가 필요**로 표시될 수 있습니다. 부족한 내용을 반복 문장이나 빈 페이지로 채워 완성된 분석으로 표시하지 않습니다.

분석 화면과 PDF 첫머리에서 **학업·진로·공동체 3역량과 학생부 8영역별 평가 관점**을 확인합니다. 프로젝트 지식베이스의 학종 시행계획과 학습 자료에 근거한 교육적 해석이며, 모든 대학에 적용되는 공통 배점표는 아닙니다.

## 4. 결과 대시보드: 대학·학과별 학종 준비

1. 학생부의 로컬 분석을 확인하고 기본자료를 **저장**합니다.
2. **결과 대시보드 → 대학·학과 준비**에서 준비할 목표 카드를 선택합니다.
3. **전략 생성**을 누릅니다. 공개 자료와 허용된 학습 분류를 연결하여 다섯 영역을 작성합니다.
4. 각 항목의 준비 내용·연결 이유·구체적인 방법과 근거를 확인합니다.

| 다섯 상세 영역 | 확인할 내용 |
| --- | --- |
| 목표와 공식 자료 | 대학·학과·대입 학년도, 공개 자료의 발표 단계와 적용 범위 |
| 대학의 평가와 전공의 학습 기반 | 공개된 평가 관점과 학습 기반을 구분하여 읽기 |
| 학생과 목표의 대조 | 확인한 강점·보완점이 목표의 준비 관점과 연결되는 이유 |
| 준비 우선순위 | 유지할 공부, 보완할 개념·기능, 과목 선택과 추가 확인 조건 |
| 학교에서 가능한 준비 | 실제 과제·활동의 조건과 준비 대안 |

여러 목표는 **대학·학과 조합별로 각각** 생성합니다. 시행계획과 다른 학년도 자료는 참고 범위를 확인하며, 전공 분류의 일반적인 학습 제안을 대학의 공식 입학평가 기준으로 바꾸어 읽지 않습니다. 이 결과는 합격 확률이나 자동 적합성 판정이 아닙니다.

기존 화면의 **학습·진로 전략 생성**은 새 결과 대시보드로 이어집니다. 새 전략은 이 대시보드의 목표별 생성 기능을 사용하고, 예전 직접 작성 내용은 **기존 전략 기록**에서 이어서 확인합니다.

## 5. 질문 중심 학습과 선택 입력 반영하기

**질문 중심 학습**에서는 같은 목표의 최신 학종 준비 전략을 바탕으로 질문과 학습 방법을 만듭니다.

1. **질문 중심 학습** 탭에서 대학·학과 카드를 확인합니다.
2. **전략 생성**을 누릅니다. 앞 단계의 전략이 없거나 입력이 바뀌었다면 학종 준비 전략을 먼저 생성·갱신합니다.
3. 중심 질문의 선정 이유와 개념 학습, 탐구 설계, 학교 과제 연결, 성찰과 다음 학습의 다섯 영역을 읽습니다.
4. 아직 하지 않은 실험·활동·성찰을 이미 완료한 사실처럼 적지 않았는지 확인합니다.

예를 들어 “관찰 자료의 차이는 어떤 조건에서 달라지는가?”처럼 무엇을 비교하거나 설명할지 드러나는 질문을 사용합니다. 자료를 구하기 어려우면 실제로 사용할 수 있는 교과서·문헌·공개자료의 대안을 확인합니다.

**교사 관찰·상담**과 기본자료의 관찰·의견은 어느 단계에서든 선택하여 추가할 수 있습니다. 상담의 **학생 반응·합의한 방향·수정할 점·상담 요약**은 실제로 확인한 내용을 적습니다. 작성 중에는 **저장**을 사용하며, 완료 기록을 남길 때만 실제 상담일·학생 반응·합의한 방향을 입력하고 **상담 반영 완료**를 누릅니다.

입력을 바꾸면 기존 결과의 최신 여부를 다시 확인합니다. **최신 여부 확인 필요** 또는 **입력 변경 · 다시 생성**이 표시되면 저장 후 학종 준비 전략, 질문 중심 학습의 순서로 다시 생성합니다. 새 결과 생성은 학생 공개나 교사 확정을 자동으로 실행하지 않습니다.

구체적인 시간 배분은 학생이 정합니다. 시간 상한·과제 진행 상태·점검일을 등록하지 않습니다. 실제 학교 과제의 제한시간·분량·제출 형식·자료·AI 사용 조건은 그대로 지킵니다.

## 6. 결과 읽기와 PDF 저장하기

선택한 단계와 목표를 확인하고 **이 결과 PDF 저장**을 누릅니다. 문서에서 **학생이 준비할 사항**, 선택 이유, 학습 방법과 근거가 구체적인지 검토합니다.

| 필요한 문서 | 저장 방법과 범위 |
| --- | --- |
| 학생부 분석 | 학생부 분석 탭에서 현재 원본과 연결된 분석을 저장 |
| 대학·학과별 학종 준비 전략 | 대학·학과 준비 탭에서 선택한 목표의 결과를 저장 |
| 질문 중심 학습 전략 | 질문 중심 학습 탭에서 선택한 목표의 결과를 저장 |
| 기존 직접 작성 자료 | 기존 보고서 기능에서 현재 자료·전략 PDF를 저장 |
| 편집 가능한 전체 이력 | 전략 백업 저장으로 JSON 보관 |

두 새 전략 PDF는 **목표 조합별로 각각 최소 다섯 본문 장**으로 구성하고, 내용이 길면 여러 페이지로 이어집니다. 다섯 영역의 구체적인 설명·이유·방법이 부족하거나 같은 설명을 반복한 결과는 PDF 완성본으로 저장하지 않습니다. 학생부 분석은 자료 범위에 따라 부분 분석임을 밝히며 기존 분석 결과도 확인할 수 있습니다.

생성 전, 입력 변경 후, 가져온 미검증 자료에서는 PDF 버튼이 비활성화되거나 재확인 안내가 나올 수 있습니다. 저장만으로 예전 결과가 최신 결과가 되지는 않습니다. 원본 연결을 확인하고 관련 결과를 다시 생성하세요.

PDF는 읽기·전달용이며 편집 상태를 복원하지 않습니다. 교사용 근거와 학생에게 설명할 내용을 검토한 뒤 필요한 파일을 전달합니다. 학생 이름을 붙인 화면·PDF·이전 결과 전체를 다음 외부 AI 요청에 다시 첨부하지 않습니다.

## 7. 학생에게 전달하기와 기존 기록 보존하기

새 대시보드와 PDF는 PC에서 확인·보관합니다. 학생에게 필요한 설명을 검토한 뒤 PDF 파일을 직접 전달하세요. **생성·다운로드만으로 온라인 학생 화면에 공개되지 않습니다.**

기존 학생 안내 기능은 **기존 전략 기록**의 작성·검토·확정 절차를 유지합니다. 학생 안내 메시지와 구체적인 계획을 확인하고 교사가 확정한 뒤 학생 안내 PDF를 받을 수 있습니다. 온라인 학생 안내는 별도의 학생 계정·참여 승인·담당 연결과 명시적인 공개 작업이 필요합니다.

교사 관찰·상담 원문, 학생부 원문, 로컬 상세 분석과 내부 근거 연결은 학생 화면에 자동 공개하지 않습니다. 새 대시보드의 외부 AI 생성과 온라인에 학생 기록을 저장·게시하는 작업은 구분됩니다.

확정하거나 안내한 회차를 수정하려면 **회차 추가**로 이어갑니다. 기존 전략을 보존하면서 새 회차에서 필요한 자료와 전략을 다시 확인합니다.

## 8. 저장과 백업 이어 쓰기

1. 화면을 닫기 전 **저장**을 누르고 **저장된 기록**을 확인합니다.
2. 같은 PC에서 전략실을 다시 열고 왼쪽 목록의 학생과 회차를 선택합니다.
3. 중요한 작업 전후에는 **전략 백업 저장**으로 전체 회차를 보관합니다.

백업에는 학생부·분석·교사 입력과 새 대시보드의 로컬 근거 연결이 포함될 수 있습니다. **새 전략 결과가 담긴 백업도 로컬 전용**입니다. 원본 학생부 항목을 지우거나 기록 구분을 바꾸어 온라인으로 가져올 수 없습니다.

**전략 백업 가져오기**는 학생을 확인한 뒤 새 사본으로 엽니다. 이전 확정·공개·근거 확인을 현재 교사의 승인으로 승계하지 않습니다. 원본 학생부를 다시 확인하고 필요한 분석과 전략을 새로 생성하세요. 이전 실행과제·점검일·사전 전략 사본은 이력에 보존되며 새 흐름에서 관리할 필요는 없습니다.

기본 기록 폴더는 **%LOCALAPPDATA%\DaeryunCounsel**입니다. 내려받은 백업·PDF도 학생 자료를 보관할 수 있는 위치에 저장합니다. 온라인 기록과 PC 기록은 자동 동기화되지 않습니다.

## 부록. 학생부 PDF를 교사 PC에서 분석하기

### 처음 한 번 준비하기

1. Windows PC에 Python 3.11 이상을 준비합니다. 학생부 분석에는 Ollama와 내려받은 로컬 모델이 필요합니다.
2. **교사 PC용 실행기 내려받기**로 받은 압축을 풀고 **상담실_설치.cmd**를 실행합니다.
3. **상담실_시연.cmd**의 합성 자료로 연습할 수 있습니다. 시연은 실제 학생부나 실제 외부 AI 성공을 확인하는 절차가 아닙니다.
4. 시연을 종료하고 **상담실_교사용.cmd**를 실행한 뒤 학교 교사 계정을 연결합니다.

### PDF부터 세 결과물까지

1. **학생 자료·로컬 분석 → 학생부 PDF 근거**에서 PDF 한 개를 선택하거나 끌어 놓습니다. 20MB·80쪽 이내이며 필요한 경우 암호를 입력합니다.
2. **항목 추출하기**를 누르고 원문·페이지·학년·학기를 대조합니다.
3. **학생부 상세 분석 → 분석 설정**에서 로컬 모델을 확인하고 **분석 시작**을 누릅니다.
4. **결과 대시보드 → 학생부 분석**에서 근거와 해석을 확인합니다.
5. 희망 대학·학과를 저장하고 **대학·학과 준비**, **질문 중심 학습**을 차례로 생성합니다.
6. 결과를 검토한 뒤 단계별 **이 결과 PDF 저장**을 사용합니다.

학생부 추출·분석은 로컬에서 처리합니다. 후속 전략의 외부 요청에는 로컬에서 정해진 분류로 변환한 학습 특성·지원 목표·일반화된 활동 조건만 사용합니다. 자유롭게 입력한 문장, 학생·학교 이름, 원문 파일·상세 분석·교사 노트는 보내지 않습니다. 개인정보를 지우기 위해 학생부를 외부 AI에 올리는 경로는 없습니다.

이 프로젝트의 지식베이스에서 선택한 실제 과제·동아리 이름과 출처·조건은 PC에서 결과에 연결합니다. 실제 운영 학년도·수강·참여 여부와 AI 사용 금지 등 원문 조건을 확인하세요. 이전 온라인 일반 AI 입력 경로는 차단되며, 새 전략은 PC의 비식별 생성 경로를 사용합니다.

종료 전 저장한 뒤 실행 창에서 **Ctrl+C**를 누릅니다. 같은 PC의 기록은 보존됩니다.
