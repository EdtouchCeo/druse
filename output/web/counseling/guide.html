대륜고 상담실 설치·사용 안내

담당 교사와 학생이 상담을 이어가고, 교사는 자신의 PC에서 학생부를 분석할 수 있습니다.

온라인 상담실 열기교사용 로컬 상담실 내려받기

온라인 상담 시작하기

  1. 대륜고 사용설명서에 로그인한 뒤 상담실을 엽니다.
  2. 학교의 상담 권한 승인과 담당 학생 배정이 완료되면 교사는 상담을 작성하고 학생은 본인 상담을 확인할 수 있습니다.
  3. 학생 질문·확인한 근거·교사 의견·다음 행동을 저장합니다. 문체와 내용을 점검한 뒤 교사가 확인하여 확정합니다.
  4. PDF와 JSON을 함께 내려받습니다. 다음 상담에서는 JSON을 가져오거나 회차를 추가하여 이전 기록을 이어갑니다.

일반 상담은 학교 서비스의 비공개 보관함에 저장됩니다. 학번이 바뀌어도 같은 학생의 이력을 이어가도록 고정 학생 ID를 사용합니다.

교사 PC에 설치하기

  1. Windows PC에 Python 3.11 이상을 준비합니다. 학생부 AI 분석에는 Ollama와 미리 내려받은 로컬 모델도 필요합니다.
  2. 위 실행 파일을 내려받아 압축을 풉니다. 묶음에는 AI 모델과 학생 자료가 포함되어 있지 않습니다.
  3. 상담실_설치.cmd를 실행합니다. 이 단계는 인터넷에서 실행 라이브러리를 설치합니다.
  4. 먼저 상담실_시연.cmd를 실행하여 제공된 합성 학생부로 사용 흐름을 확인합니다.
  5. 실제 교사용은 시연 창을 종료한 뒤 상담실_교사용.cmd를 실행합니다. 화면에서 대륜고 계정으로 연결을 선택하고 학교 연결 창에서 이 PC 주소를 확인합니다.

승인된 상담 교사만 실제 자료를 사용할 수 있습니다. 로그인이 필요하면 연결 창을 유지한 채 사용설명서에 로그인합니다. 종료할 때 실행 창에서 Ctrl+C를 누르면 기록은 보존됩니다.

학생부 분석과 상담

  1. 상담 학생을 확인하고 학생부 PDF를 불러옵니다.
  2. 추출된 항목·학년·학기·페이지를 확인합니다. 작성 중인 학생부는 채워진 부분만 분석하고 중학교 항목은 원래 이름을 보존하여 연결합니다.
  3. 로컬 모델과 학생 목표를 선택하여 분석합니다. 강점·보완점의 원문 근거와 다음 행동을 확인합니다.
  4. 문체 점검 후 교사가 직접 내용과 근거를 검토하고 회차를 확정합니다.
  5. PDF와 JSON을 저장합니다. 학생부가 포함된 사본을 다시 확정하려면 원본 PDF를 재업로드하여 대조해야 합니다.

정상 공란·미기재·판독 불확실을 학생의 약점으로 판단하지 않습니다. 스캔 PDF는 이미지 판독을 지원하는 로컬 모델이 필요하며 읽지 못한 내용은 확인 필요로 남깁니다. PDF 한도는 20MB·80쪽입니다.

PDF와 JSON을 함께 보관하세요

PDF는 결과를 읽고 출력하는 보고서입니다. 온라인에서는 인쇄 창에서 PDF 저장을 선택합니다. JSON은 상담 회차와 다음 행동을 다시 불러오는 백업입니다. PDF만으로 편집 가능한 상담을 복원하지는 않습니다.

확정 회차는 보존하고 새 회차에서 이어 씁니다. 가져온 파일의 과거 확인 이력은 현재 교사의 확인으로 승계되지 않습니다.

자료 저장과 AI 선택

학생부 PDF·분석·전략·AI 문체 검토는 교사 PC의 로컬 Ollama만 사용합니다. 외부 AI로 자동 전환하거나 온라인 상담에 자동 동기화하지 않습니다. 로컬 자료는 기본 %LOCALAPPDATA%\DaeryunCounsel에 보관됩니다. PDF·JSON도 OneDrive와 동기화되지 않는 폴더에 저장하세요.

온라인 일반 상담에는 학교 서버 AI, 개인 Gemini, 개인 Ollama를 선택할 수 있습니다. 서버 AI는 학교의 연결 설정에 따라 표시됩니다. 학생부 프리미엄 자료에는 이 선택을 적용하지 않습니다.

학교 관리자의 첫 설정

기존 학교 관리자가 승인된 계정으로 로그인하면 상담 권한 관리가 연결됩니다.

  1. 학교 회원 승인을 확인하고 교사·학생의 상담 권한을 승인합니다.
  2. 학생 계정에 학년도·학번·학교급·학년을 등록합니다.
  3. 학생에게 담당 교사를 배정합니다.

관리자 역할만으로 학생 상담을 열람할 수는 없습니다. 실제 상담은 담당 교사 권한으로 진행합니다.

문제가 생기면

모델이 보이지 않으면 Ollama와 로컬 모델 설치를 확인하세요. 저장 충돌이 표시되면 작성분을 JSON으로 백업한 뒤 최신 상담을 불러오세요. 인용·형식 검증에 실패한 분석은 확정하지 말고 원문 추출 상태를 확인하세요.

오류를 전달할 때는 발생 단계와 오류 문구만 사용하고 학생부 본문·로그인 정보·개인 API 키를 포함하지 마세요.

버전 0.2.0 · 2026년 9월 12일. AI 결과와 자동 점검은 교사의 교육적 판단과 실제 상담을 대신하지 않습니다.
