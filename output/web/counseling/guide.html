학생: 나에게 안내된 전략 확인하기

학교 계정으로 로그인한 뒤 학습전략에서 전략실을 엽니다. 담당 교사가 안내한 목표, 강점·보완점, 교과·탐구·활동 계획과 실행 과제를 읽고 PDF로 저장합니다. 아직 안내된 전략이 없다면 빈 안내 화면이 표시됩니다. 현재 버전에서 전략과 과제 상태는 담당 교사가 수정합니다.

  3. 상담실_설치.cmd를 실행하여 필요한 라이브러리를 설치합니다. 기존 실행 파일 이름은 호환을 위해 유지합니다.

JSON 백업은 전략·회차·과제 이력을 다시 불러오는 파일입니다. PDF만으로 편집 상태를 복원하지는 않습니다. 가져온 확인·안내 이력은 새로운 교사의 확인이나 학생 공개로 승계되지 않습니다. 학생부 분석이 포함된 사본은 원본 PDF를 다시 불러와 확인하고 재분석한 뒤 확정합니다.
