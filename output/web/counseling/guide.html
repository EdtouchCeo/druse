학종 전략실 이용 안내

대륜고 학종 전략실 설치·사용 안내

교사가 학생 자료의 근거를 살펴보고 사전 전략을 먼저 수립합니다. 준비한 계획으로 학생과 실제 상담을 진행하고, 학생의 반응·합의한 방향·수정할 점을 반영해 최종 전략을 완성합니다. 학생에게는 교사가 검토·확정하고 명시적으로 안내한 결과물만 보입니다.

학종 전략실 열기교사용 로컬 앱 내려받기

교사: 사전 전략 → 학생 상담 → 최종 전략 안내

  1. 학생·학부모 안내 오른쪽 학습전략에서 전략실을 엽니다. 로그인이 필요하면 로그인하고 전략실로 이동을 누릅니다. Google 학교 계정으로 로그인하면 같은 탭에서 전략실로 자동으로 돌아옵니다. 처음 이용하는 계정은 회원 정보를 입력한 뒤 돌아옵니다. 승인된 담당 교사는 배정된 학생을 선택합니다.
  2. 01 자료·분석에서 관심·전공·실제 이수 과목·성적·학습 고민·습관·활동·독서·교사 관찰·주간 가용 시간을 아는 만큼 입력합니다. 관찰 근거와 관련 학교 자료를 먼저 읽습니다.
  3. 교사가 선택할 전략 방향에서 교과 준비, 학습 사례 분류와 피드백, 탐구 설계, 활동 근거 확보, 실행 범위와 점검 기준을 비교해 계획을 선택합니다. 제안은 빈 전략 항목과 실행과제에 반영되며 교사가 편집·저장합니다. 상담 질문은 계획을 확인하는 보조 자료입니다.
  4. 02 교사 전략 수립에서 제목과 구체적인 계획·실행과제를 작성합니다. 전략 준비 완료·상담으로를 누르면 이 시점의 전략과 실행과제를 읽기 전용 사본으로 보존합니다. 준비 완료는 최종 확정이나 학생 공개가 아닙니다.
  5. 03 학생 상담·반영에서 사전 전략을 학생과 대조합니다. 실제 상담일·학생 반응·합의한 방향을 입력하고 수정할 점과 상담 요약을 남깁니다. 예상 반응을 결과로 채우지 않습니다. 상담 반영 완료 후 최종 전략으로 이동합니다.
  6. 04 최종 결과물에서 상담을 반영해 전략·실행과제·학생 안내 메시지를 수정합니다. 저장한 최종 내용의 문체와 근거를 점검하고 교사가 확인하여 확정합니다. 상담 완료만으로 전략이 자동 수정되지는 않습니다.
  7. 온라인에서는 학생에게 전략 안내를 눌러 최종 회차를 공개합니다. 확정만으로 학생에게 안내되지 않습니다. 로컬에서는 상담 반영 완료와 최종 확정 후 학생 안내 PDF를 만들어 교사가 직접 전달합니다.
  8. 다음 회차는 이전 전략·기본자료·미완료 과제를 참고하여 새 사전 전략과 실제 상담을 진행합니다. 이전 사전 사본·상담·최종 안내 이력은 보존됩니다.

학생 기본자료·성적 원자료·사전 전략 사본·상담 기록·교사 참고 메모는 교사용입니다. 학생에게는 안내된 최종 전략과 실행과제만 보이며 비공개 자료는 학생 조회·학생용 백업·학생 안내 PDF에서 제외됩니다.

전략실에서 시작한 로그인은 전략실로 돌아옵니다. 사용설명서의 일반 로그인 버튼으로 시작하면 기존처럼 학교 화면으로 이동합니다. 학교 승인과 전략실 참여 권한은 별도로 확인합니다.

자료를 관찰하고 전략을 선택하는 기준

입력에 따른 관찰 근거와 교사가 선택할 전략 카드 3~5개를 제공합니다. 카드 순서는 자동 진단이나 우선순위 판정이 아닙니다. 같은 과목·같은 등급 체계의 성적만 관찰하고 5등급·9등급·성취도를 환산하지 않습니다. 성적 변화만으로 지원 우선순위를 정하거나 합격 가능성을 추정하지 않습니다.

미입력은 추가 확인으로 남깁니다. 주간 가용 시간이 0분이면 기존 수업·활동 안에서 실행할 계획을 제안하고, 시간이 미확인이면 추가 배정을 보류합니다. 학생이 이미 했다고 입력한 경험과 앞으로 교사가 제안하는 활동을 구분합니다.

평가 과제 111개·동아리 29개·학급 특색활동 28개를 연결했습니다. 학교급·학년·학년도·학기·실제 이수 과목, 원문 시기·AI 및 자료 조건·채점표 발췌·출처를 확인합니다. 후보를 현재 배정 과제로 확정하지 않습니다. 동아리의 확인된 대상 학년과 미확인 범위를 구분하며 중학생에게 고교 자료는 진학 전 탐색용입니다.

학생: 나에게 안내된 최종 전략 확인하기

학습전략에서 전략실을 열고 로그인하고 전략실로 이동을 누릅니다. Google 학교 계정으로 로그인하면 같은 탭에서 전략실로 자동으로 돌아옵니다. 담당 교사가 상담 내용을 반영하고 검토·확정하여 안내한 목표·교과·탐구·활동 계획과 실행과제를 읽고 PDF로 저장합니다. 안내된 전략이 없다면 빈 안내 화면이 표시됩니다. 사전 전략과 상담 원기록은 학생에게 공개되지 않으며 현재 버전에서 전략·과제 상태는 담당 교사가 수정합니다.

교사 PC에 로컬 앱 설치하기

  1. Windows PC에 Python 3.11 이상을 준비합니다. 학생부 AI 분석에는 Ollama와 미리 내려받은 로컬 모델도 필요합니다.
  2. 실행 파일 묶음을 내려받아 압축을 풉니다. AI 모델과 실제 학생 자료는 포함하지 않습니다.
  3. 상담실_설치.cmd를 실행하여 필요한 라이브러리를 설치합니다. 기존 실행 파일 이름은 호환을 위해 유지합니다.
  4. 상담실_시연.cmd로 제공된 합성 자료를 먼저 확인합니다.
  5. 실제 교사용은 시연 창을 종료한 뒤 상담실_교사용.cmd를 실행합니다. 화면에서 대륜고 계정으로 연결을 선택하고 학교 연결 창에 표시된 이 PC 주소를 확인합니다.

승인된 교사만 실제 자료를 사용할 수 있습니다. 학교 연결 창에서 로그인이 필요하면 로그인하고 전략실로 이동을 눌러 새 탭에서 로그인합니다. 원래 연결 창으로 돌아와 로그인 상태 다시 확인을 누르고, 이 PC 주소와 교사 계정을 확인한 뒤 이 PC 연결을 직접 누릅니다. 로그인만으로 로컬 연결을 승인하지 않습니다. 실행 창에서 Ctrl+C를 누르면 서버가 종료되며 기록은 보존됩니다.

프리미엄: 로컬 분석에서 상담 후 최종 전략까지

  1. 학생을 확인하고 교사 PC에서 학생부 PDF를 불러옵니다. 출결부터 행동특성 및 종합의견까지 채워진 항목과 학년도·학년·학기·페이지를 확인합니다.
  2. 로컬 Ollama로 분석하고 강점·보완점의 원문 근거를 대조합니다. 중학교 학생부도 원래 항목을 보존하여 연결합니다.
  3. 교사가 분석과 입력 자료를 바탕으로 사전 전략을 작성하고 준비 완료합니다. 준비 시점의 사본은 상담 후에도 바뀌지 않습니다.
  4. 학생과 실제 상담을 진행하여 반응·합의한 방향·수정할 점을 이 PC에 기록하고 상담 반영을 완료합니다.
  5. 최종 전략과 실행과제를 수정한 뒤 문체·근거 검토와 교사 확정을 진행합니다. 학생 안내 PDF 저장으로 비공개 준비·상담 자료를 제외한 최종 안내문을 만듭니다.
  6. 교사가 PDF를 학생에게 직접 전달합니다. 학생부·분석·파생 전략과 이에 관한 사전 사본·상담·최종 결과물은 온라인에 게시하거나 동기화하지 않습니다.

미기재·정상 공란·판독 불확실을 학생의 약점으로 판단하지 않습니다. 스캔 PDF는 이미지 판독을 지원하는 로컬 모델이 필요하며 읽지 못한 내용은 확인 필요로 남깁니다. PDF 한도는 20MB·80쪽입니다.

교사 준비서·학생 안내 PDF·JSON의 구분

교사용 사전 전략 준비서는 상담 전에도 출력할 수 있으며 교사가 자료와 계획을 확인하는 문서입니다. 상담 후 교사용 보고서는 사전 사본·상담 반영·최종 전략을 대조하는 용도입니다. 기본자료·성적표·교사 메모와 로컬 분석 근거가 포함될 수 있으므로 학생 안내용과 구분합니다.

학생 안내 PDF는 상담 반영 완료와 현재 최종 내용의 교사 확정 후 만듭니다. 최종 전략과 실행과제를 담고 기본자료·사전 사본·상담 기록·학생부 원문·분석 상세·교사 메모는 제외합니다. 온라인에서는 명시적으로 안내한 회차를 학생이 확인하며 PDF는 인쇄 창에서 저장합니다.

교사용 JSON 백업은 기본자료·사전 전략·상담·최종 전략·회차 이력을 다시 불러오는 파일입니다. 가져온 사전 전략은 검증되지 않은 참고본입니다. 이전 작성자·시각을 현재 교사의 확인 이력으로 간주하지 않으며 상담을 다시 확인·완료하고 최종 전략을 검토·확정합니다. 가져온 확정·학생 안내 상태도 새 승인이나 공개로 승계되지 않습니다. 학생부 분석 사본은 원본 PDF를 다시 불러와 확인·재분석합니다.

보관 위치와 AI 선택

학생부 PDF·분석·파생 전략·AI 문체 검토는 교사 PC의 로컬 Ollama만 사용합니다. 사전 준비·상담 기록·최종 결과물도 로컬에 보관하고 외부 AI로 전환하거나 온라인에 동기화하지 않습니다. 기본 보관 위치는 %LOCALAPPDATA%\DaeryunCounsel입니다. 내려받은 PDF·JSON도 동기화되지 않는 폴더에 보관합니다.

직접 입력한 온라인 일반 전략의 보조 AI는 학교 서버 AI·개인 Gemini·개인 Ollama 중 선택하며 화면의 전송 범위를 확인합니다. 이 선택을 학생부 프리미엄 자료에 적용하지 않습니다. 학번이 바뀌어도 같은 학생의 이력을 이어가도록 내부 고정 ID와 학년도별 학번을 연결합니다.

학교 관리자의 첫 설정

  1. 기존 학교 관리자가 승인된 계정으로 로그인하여 교사·학생 이용 권한을 승인합니다.
  2. 학생 계정에 학년도·학번·학교급·학년을 등록합니다.
  3. 학생에게 담당 교사를 배정합니다.

관리자 역할만으로 학생 전략을 열람할 수는 없습니다. 전략 작성과 안내에는 담당 교사 권한이 필요합니다.

문제가 생기면

상담을 시작할 수 없으면 제목과 구체적인 계획을 작성하여 사전 전략 준비를 완료합니다. 최종 검토나 학생 PDF가 막히면 실제 상담일·학생 반응·합의한 방향을 입력하여 상담을 완료한 뒤 최종 내용을 검토·확정합니다. 학생 화면이 비어 있다면 명시적 안내 여부와 담당 배정을 확인합니다.

모델이 보이지 않으면 Ollama와 로컬 모델 설치를 확인합니다. 저장 충돌은 작성분을 JSON으로 백업한 뒤 최신 기록을 불러옵니다. 원문 인용 검증에 실패하면 추출 상태를 확인합니다. 오류를 전달할 때는 발생 단계와 오류 문구만 사용하고 학생부 본문·로그인 정보·개인 API 키를 포함하지 않습니다.
