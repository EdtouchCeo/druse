# 대륜고 수행평가 준비

학교생활에 연결한 독립 Vue 작성 도구입니다. EdTouch 알고리즘 아이디어 작성실과 비즈씽킹의 단계별 작성·예제·캔버스 패턴을 대륜고 과제에 맞춰 재구성했습니다. 원본 EdTouch 앱과 인증은 변경하지 않습니다.

## 실행과 빌드

Node 24 LTS에서 검증합니다. 이 폴더에서 실행합니다.

```sh
npm ci
npm run typecheck
npm test
npm run build
```

Windows PowerShell에서 스크립트 실행 정책으로 npm이 막히면 `npm.cmd`를 사용합니다. 빌드 결과는 저장소의 `output/web/assessment/`에 복사합니다. 이 정적 결과물을 소스·잠금 파일과 함께 커밋합니다. Netlify의 기존 공개 폴더 `output/web`와 다른 서비스의 빌드 경로는 바꾸지 않습니다.

브라우저 테스트는 로컬 정적 서버로 `output/web`를 연 뒤 실행합니다.

```sh
python -m http.server 5188 --bind 127.0.0.1 --directory output/web
```

## 주소와 학습 자료

학생·학부모 안내의 `평가과제 도움 자료`에서 도구를 엽니다. `/#student/assessment-help/subject`는 교과 자료와 두 작성 도구, `/#student/assessment-help/activity`는 진로활동 계획서 다운로드입니다. 두 작성 도구의 복귀 링크는 교과 자료로 연결됩니다.

- `/assessment/`: 두 도구와 저장한 원고의 진입점.
- `/assessment/social-plan/`: 제공된 문제 상황을 선택해 읽고 디자인 싱킹 5단계를 작성합니다. 기법별 질문은 경로 8개, 지역·게임 트리·전문가 각각 10개입니다.
- `/assessment/business-model/`: 린 캔버스 9항목. 인터뷰가 없어도 작성할 수 있습니다.

`2026 예제`의 사회 문제 예제 4개와 비즈니스 예제 4개를 대응쌍으로 제공합니다. 기존 연습 문제 3개와 신규 경로 연습 1개를 구분해 표시합니다. 사용자 제공 질문·예시 38개의 순서를 보존합니다. 상위 폴더에 있던 다른 캔버스 양식·일정·배점·최소 작성 개수는 적용하지 않습니다.

문제 상황은 학생 입력 항목이 아닙니다. 연습 네 종류를 각각 네 문단으로 제시하며, 상황을 바꿀 때는 기존 답변을 보존하고 새 원고를 만듭니다. 예전에 저장한 상황도 읽기 전용으로 보존합니다. 작성 진척은 공감부터 평가까지 다섯 항목을 세며, 출력에는 제공된 상황과 학생이 작성한 다섯 항목을 함께 담습니다.

질문, 예제, 문장 시작 도움과 자기 점검은 생성형 AI 없이 작동합니다. 자동 채점이나 외부 AI 문장 검토는 제공하지 않으며 외부 모델로 학생 글을 보내지 않습니다. 학생이 쓴 내용을 바탕으로 확인 질문을 읽고 직접 수정합니다.

## 저장과 출력

IndexedDB `daeryun-assessment:v1`의 `projects`에 원고·이미지·점검 기록을 저장합니다. 서버에는 저장하지 않습니다. 다른 기기는 JSON 백업으로 옮깁니다. 불러온 파일은 기존 원고를 덮어쓰지 않는 새 프로젝트가 됩니다.

저장할 때 원고 버전을 같은 트랜잭션 안에서 비교합니다. 두 창에서 수정하면 뒤늦은 변경은 사본으로 보관합니다. 저장 실패 시 기존 원고를 보존하며 백업 수단을 안내합니다.

인쇄는 별도 창을 열어 브라우저의 PDF 저장 기능을 사용합니다. 두 문서는 분리해서 출력하며 작성 도움·예제·점검 기록은 기본 제출 본문에서 제외합니다. 사용자가 넣은 출처·이름·스케치는 출력에 포함됩니다. 백업 파일과 출력물의 사용자 문장은 HTML로 실행되지 않도록 처리합니다.

## 콘텐츠 유지관리

- `src/data/questionBank.ts`: 원문 질문·예시, 개념 주의사항, 질문별 작성 도움.
- `src/data/examples.ts`: 사회 문제 6부분과 린 캔버스 9항목의 완성 예제.
- `src/data/practiceProblems.ts`: 문제 상황과 변경할 조건. 연습 답안을 자동으로 채우지 않습니다.
- `src/data/writingGuides.ts`: 과제 항목, 단계별 질문·문장 틀·점검 기준.

소스 변경 후 타입·핵심 테스트와 빌드를 수행하고, 화면에서 글 작성·복구·PDF를 확인합니다. 대륜고 `output/web/index.html` 전체를 낡은 셸 템플릿으로 재조립하지 않습니다. 기존 진로활동 계획서 다운로드와 학교생활 탭을 보존합니다.
